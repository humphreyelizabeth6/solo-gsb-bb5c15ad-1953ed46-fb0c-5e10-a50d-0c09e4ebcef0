# 访谈转录质性分析工作台

用于访谈转录文本的质性编码（qualitative coding）Web 工作台：按字符区间给文本片段添加**可重叠**编码，实时检测同名与嵌套冲突，并提供合并 / 拆分 / 保留边界三种决策。数据落盘 SQLite，刷新、重启均可恢复。

技术栈：React 18 + Vite · FastAPI · SQLite · Docker Compose

## 一键启动

```bash
docker compose up --build
```

## 访问地址

| 入口 | 地址 |
| --- | --- |
| Web 工作台 | http://localhost:8080 |
| 后端 API（Swagger 文档） | http://localhost:8000/docs |
| 健康检查 | http://localhost:8000/api/health |

数据保存在名为 `qual-data` 的 Docker 卷中（容器内路径 `/data/app.db`），删除容器不丢数据。

## 功能说明

- **区间编码**：在文本上**拖选**，或在表单中直接输入半开区间 `[起始, 结束)`，选择既有编码或新建编码即可添加标注；支持对同一文本叠加多个编码（重叠高亮以渐变条带呈现）。
- **冲突实时检测**：提交前先调用 `POST /api/codings/preview` 检测——
  - **同名冲突**：相同编码的区间相互重叠；
  - **嵌套冲突**：不同编码的区间互相包含（含两个方向）。
- **三种决策**：
  - **合并 merge**：同名且重叠/相邻的编码合并为一个连续区间（传递闭包）；
  - **拆分 split**：沿新区间边界拆分外层编码；若新区间包含他者，则新区间自身绕开拆分；
  - **保留边界 keep**：不做调整，重叠 / 嵌套共存。
- **编辑与删除**：侧栏标注列表支持定位（滚动 + 闪烁）、编辑（改区间或改编码，同样走冲突检测）、删除。
- **检索批量编码**：右侧「检索批量编码」面板输入**字面关键词**（非正则），`GET /api/documents/{id}/search` 返回当前文档全部命中的稳定半开区间与前后文，**彼此重叠的命中也一并返回**（如 `aa` 在 `aaa` 中命中 `[0,2)` 与 `[1,3)`）；前端逐项勾选或全选，选择一个**既有编码**后批量提交——
  - `POST /api/codings/batch` 在**单个事务**中先校验全部区间，任一非法（`end <= start` 或超出文本长度）即整批回滚、不落库；
  - 校验通过后逐项写入：与既有标注**完全相同**（同编码、同区间）的项记为**跳过**，其余按 **keep（保留边界）** 原样写入，不做合并 / 拆分；
  - 返回**新增与跳过明细**（跳过项附带既有标注 id），提交成功后正文高亮与编码计数随即刷新；单条标注的冲突检测与决策流程不受影响。
- **编码筛选**：编码本复选框控制文本高亮、标注列表、共现矩阵与说话人分析的显示范围。
- **编码共现视图**：正文区顶部切换到「编码共现」标签，按当前文档展示编码两两关系矩阵——
  - 计算口径：先分别**合并同一编码自身重叠或相邻（首尾相接）的半开区间**，再对每对编码求区间交集，保证共享字符不被重复计数；
  - 矩阵可在**共现覆盖字符数**（交集各段长度之和）与**共现片段数**（交集被编码边界切成的段数）两种指标间切换，单元格按数值相对最大值**深浅着色**；对角线灰色显示该编码自身合并后的覆盖，仅供参考；
  - 点击非零单元格列出对应**交集片段及原文摘录**，点击片段自动切回正文、滚动并闪烁定位高亮；
  - 编码筛选变化后矩阵与片段明细同步更新；无共现或未勾选编码时给出明确空状态。
  - 对应 `GET /api/documents/{id}/cooccurrence?codes=…`。
- **说话人分析视图**：正文区顶部切换到「说话人分析」标签，按文档中形如「说话人：内容」的发言段落（行首标签 + 全角/半角冒号，段落延伸至下一说话人行首）统计每位说话人——
  - 表格列出每位说话人的**发言段落数、文本长度、总覆盖（选中编码并集）及各编码覆盖字符数与覆盖率**（覆盖率 = 覆盖字符数 ÷ 文本长度）；文首无法识别说话人的文本归入**未标注说话人**；
  - 计算口径：同一编码的重叠标注**先合并再裁剪到发言段落**，共享字符不重复计数；全部发言段落与未标注部分恰好覆盖整篇文档；
  - 顶部**说话人筛选**复选框控制表格行显示，底部给出当前显示说话人的合计行；
  - 点击说话人名查看其发言段落，点击覆盖统计单元格查看覆盖片段与原文摘录，点击片段自动切回正文、滚动并闪烁定位高亮；
  - 编码筛选变化后统计列同步更新；未识别到发言段落或未选择编码时给出明确空状态。
  - 对应 `GET /api/documents/{id}/speakers?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **跨文档分布对比视图**：正文区顶部切换到「分布对比」标签，对**全部文档**按所选编码汇总**标注字符数、标注段数与占文档长度比例**——
  - 表格行为编码、列为文档（按文档标题稳定排序），同一编码在各文档并列对比；单元格按行内最高占比**深浅着色**，并显示相对行内最高值的**差异百分比**；
  - 计算口径：同一编码在每篇文档内先合并重叠/相邻区间再统计，共享字符不重复计数；占比 = 标注字符数 ÷ 文档长度；
  - 顶部**文档筛选**复选框控制列显示，编码筛选与其它视图联动；
  - 点击非零单元格自动**切换到该文档正文**、滚动并闪烁定位**首个对应片段**；
  - 后端在**单一快照**中计算并返回**缺失编码**（全部文档均无标注）与**空文档**（没有所选编码标注）提示，不修改任何原标注。
  - 对应 `GET /api/code-distribution?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **覆盖缺口视图**：正文区顶部切换到「覆盖缺口」标签，按当前文档与编码筛选列出**未被所选编码覆盖的连续文本区间**——
  - 计算口径：后端先把所选编码的半开标注区间**合并重叠/相邻区间**为并集，再对 `[0, 全文长度)` 求补集；**文首、文尾与零标注**（全文即一个缺口）场景均正确保留；
  - 每个缺口返回**起止位置、长度与原文摘录**；顶部摘要给出已覆盖字符数与覆盖率；
  - 前端提供**最小缺口长度**筛选（本地过滤，不重新请求）与**上一处 / 下一处**循环导航，点击缺口或导航均自动切回正文、滚动并闪烁定位；
  - 「带入编码表单」把整段缺口区间填入右侧编码表单（等同拖选效果），提交仍走原有**冲突预览**流程；
  - 编码筛选或标注变化后缺口列表同步刷新；所选编码并集覆盖全文时给出**「已全覆盖」**空状态。
  - 对应 `GET /api/documents/{id}/gaps?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **编码流转视图**：正文区顶部切换到「编码流转」标签，按当前文档展示**相邻编码状态的有向转移**——
  - 计算口径：后端把所选编码的**全部标注起止边界**切成原子区间，以**覆盖编码集合**表示区间状态；**跳过无编码区间**并**合并相邻同状态区间**（被无编码间隔分开的同状态区间不合并），再按文档顺序统计相邻状态的有向转移次数；
  - 每次转移记录**来源区间、目标区间与中间距离**（目标起点 − 来源终点，0 表示首尾相接），并按（来源状态 → 目标状态）聚合计数，列表按次数降序排列；
  - 前端支持**最小次数**与**最大间距**筛选（本地过滤，不重新请求）；展开条目查看每次转移的来源 / 目标**原文上下文**，点击实例自动切回正文、滚动并**闪烁定位来源起点到目标终点的整个跨度**；
  - 编码筛选或标注变化后转移列表同步刷新；**零标注**（无状态区间）与**无转移**（仅一段状态区间）时给出明确空状态。
  - 对应 `GET /api/documents/{id}/transitions?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **JSON 导出**：顶栏「导出 JSON」下载当前文档的完整编码结果（含每条标注的区间与原文切片），对应 `GET /api/documents/{id}/export`。
- **持久化**：所有文档、编码本、标注均存于 SQLite，刷新页面后原样恢复；首次启动自动载入一份示例访谈与编码。

## 本地开发（不用 Docker）

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
DB_PATH=./dev.db uvicorn app.main:app --reload --port 8000

# 前端（Node 20+），Vite 已配置 /api 代理到 8000
cd frontend
npm install
npm run dev   # http://localhost:5173
```

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/documents` | 文档列表 |
| POST | `/api/documents` | 新建文档 `{title, content}` |
| GET | `/api/documents/{id}` | 文档详情（含编码本与全部标注） |
| GET | `/api/documents/{id}/search?query=…` | 字面关键词检索：返回全部命中的半开区间与前后文（含彼此重叠的命中） |
| GET | `/api/documents/{id}/cooccurrence` | 编码两两共现统计，可带 `?codes=1&codes=2` 按编码筛选；返回每对编码合并后的共现字符数、片段数与原文摘录 |
| GET | `/api/documents/{id}/speakers` | 说话人分析：解析「说话人：」发言段落，返回每位说话人（含未标注说话人）的文本长度、各编码覆盖字符数与覆盖率及片段摘录；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/code-distribution` | 跨文档编码分布对比：全部文档按所选编码汇总标注字符数、段数与占文档长度比例（文档按标题稳定排序，含行内差异百分比与首个片段），单一快照返回缺失编码与空文档提示；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/gaps` | 覆盖缺口：合并所选编码重叠/相邻的标注区间后求全文补集，返回未覆盖区间的起止位置、长度与原文摘录（保留文首/文尾/零标注场景）及覆盖率；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/transitions` | 编码流转：全部标注边界切成原子区间并以覆盖编码集合表示状态，跳过无编码区间、合并相邻同状态区间后统计相邻状态的有向转移，返回每次转移的来源、目标区间、中间距离与原文摘录；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/export` | 导出 JSON（附件下载） |
| GET / POST | `/api/codes` | 编码本列表 / 新建（重名返回 409） |
| PUT / DELETE | `/api/codes/{id}` | 重命名、改色 / 删除（级联删除标注） |
| POST | `/api/codings/preview` | 冲突预览 `{document_id, code_id, start, end, exclude_id?}` |
| POST | `/api/codings` | 创建标注，可带 `resolution: keep\|merge\|split` |
| POST | `/api/codings/batch` | 批量创建 `{document_id, code_id, items:[{start,end}…]}`：单事务校验全部区间，任一非法整批回滚（422）；完全相同的既有标注记为跳过，其余按 keep 写入；返回新增与跳过明细 |
| PUT / DELETE | `/api/codings/{id}` | 修改（同样支持 resolution）/ 删除 |

## 项目结构

```
├── docker-compose.yml      # 一键启动
├── backend/
│   ├── Dockerfile
│   ├── requirements.txt
│   └── app/
│       ├── main.py           # FastAPI 路由与决策应用
│       ├── conflicts.py      # 冲突检测 / 合并 / 拆分纯函数
│       ├── cooccurrence.py   # 区间归一化 / 交集 / 共现统计纯函数

│       ├── gaps.py           # 覆盖缺口（区间并集补集）纯函数
│       ├── transitions.py    # 编码流转（状态区间切分与有向转移统计）纯函数

└── frontend/
    ├── Dockerfile          # 多阶段构建：Vite build → nginx
    ├── nginx.conf          # 静态托管 + /api 反向代理
    └── src/
        ├── App.jsx         # 状态编排与冲突决策流
        └── components/     # TextView / CodingForm / SearchBatchPanel / ConflictDialog / Sidebar / CooccurrenceView / SpeakerView / DistributionView / GapView / TransitionView
```
